# دیتاشیت جامع محیط و ساختار داده‌ها (Environment Datasheet)
**پروژه:** مسیریاب هوشمند شهری (City Router) — گام دوم  
**تدوین‌کننده:** سینا محمد پورپورانی (مسئول مستندسازی داده‌ها)  

---

<div dir="rtl">

### ۱. مشخصات عمومی محیط شبیه‌سازی
محیط مسئله در قالب یک شبکه دوبعدی گسسته مستطیلی با ابعاد زیر تعریف شده است:
- **تعداد سطرها ($ROWS$):** ۱۰ سطر (شاخص ۰ تا ۹)
- **تعداد ستون‌ها ($COLS$):** ۱۵ ستون (شاخص ۰ تا ۱۴)
- **تعداد کل سلول‌ها:** ۱۵۰ تقاطع شهری
- **مختصات تقاطع مبدأ ($START$):** خانه $(0, 0)$ در گوشه شمال غربی
- **مختصات تقاطع مقصد ($GOAL$):** خانه $(9, 14)$ در گوشه جنوب شرقی

---

### ۲. ساختار لایه‌های داده (Data Layers)
محیط شهر از دو لایه ماتریسی هم‌اندازه تشکیل یافته است:

#### لایه اول: موانع فیزیکی و ساختمان‌ها (`grid`)
- **نوع داده:** عدد صحیح باینری (`int`, $0$ یا $1$)
- **مقدار ۰:** معبر شهری باز و قابل تردد
- **مقدار ۱:** مانع فیزیکی، ساختمان مسکونی، یا بلوک غیرقابل عبور
- **احتمال مانع ($WALL\_PROB$):** ۰.۲۵ (به طور متوسط ۳۷ مانع در کل شهر، منطبق بر تنظیمات کلاس)
- **قید ایمنی:** خانه‌های مبدأ $(0,0)$ و مقصد $(9,14)$ همواره برابر ۰ تنظیم می‌شوند تا ورود و خروج عامل تضمین گردد.

#### لایه دوم: ماتریس وزن و هزینه ترافیک (`traffic`)
- **نوع داده:** عدد صحیح پیوسته در بازه $[1, 5]$
- **مفهوم مهندسی:** زمان تأخیر یا هزینه انرژی عبور از تقاطع ناشی از ازدحام خودروها:
  - **کد ۱ (روان):** کوچه‌های فرعی خلوت و بدون اصطکاک حرکتی
  - **کد ۲ (سبک):** خیابان‌های محلی با تردد روان
  - **کد ۳ (متوسط):** بلوارهای شهری با ترافیک متعارف
  - **کد ۴ (سنگین):** تقاطع‌های پرتراکم با چراغ‌های طولانی
  - **کد ۵ (بحرانی):** راهبندان شدید، گره کور ترافیکی یا کارگاه عمرانی

### ۳. شِمای فایل‌های ذخیره‌سازی داده (`JSON Schema`)
داده‌های نقشه در پوشه `maps/` با قالب استاندارد زیر سریال‌سازی می‌شوند:

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "CityRouterMap",
  "type": "object",
  "properties": {
    "metadata": {
      "type": "object",
      "properties": {
        "rows": { "type": "integer", "const": 10 },
        "cols": { "type": "integer", "const": 15 },
        "start": { "type": "array", "items": { "type": "integer" }, "minItems": 2, "maxItems": 2 },
        "goal": { "type": "array", "items": { "type": "integer" }, "minItems": 2, "maxItems": 2 },
        "wall_prob": { "type": "number", "minimum": 0, "maximum": 1 },
        "traffic_cost_range": { "type": "array", "items": { "type": "integer" } }
      },
      "required": ["rows", "cols", "start", "goal", "wall_prob"]
    },
    "grid": {
      "type": "array",
      "items": { "type": "array", "items": { "type": "integer", "enum": [0, 1] } }
    },
    "traffic": {
      "type": "array",
      "items": { "type": "array", "items": { "type": "integer", "minimum": 0, "maximum": 5 } }
    }
  },
  "required": ["metadata", "grid", "traffic"]
}
```

### ۴. متغیرها و نام‌گذاری استاندارد در کدها

| نام متغیر | نوع داده | محدوده | کاربرد و تعریف |
| :--- | :--- | :--- | :--- |
| `ROWS`, `COLS` | `int` | $10, 15$ | ابعاد ابعاد شبکه شهر |
| `WALL_PROB` | `float` | $0.25$ | نرخ چگالی موانع فیزیکی |
| `START`, `GOAL` | `tuple` | `(r, c)` | مختصات شروع و پایان جستجو |
| `MOVES` | `list[tuple]` | ۴ جهت | عملگرهای بالا، پایین، چپ و راست |
| `grid` | `np.ndarray` | $\{0, 1\}$ | ماتریس وضعیت موانع |
| `traffic` | `np.ndarray` | $[0, 5]$ | ماتریس هزینه‌های ترافیکی |
| `frontier` | `deque` / `list` | گره‌ها | مرز جستجو (صف، پشته یا هیپ اولویت) |
| `came_from` | `dict` | `cell -> prev` | درخت مسیر برای بازسازی گام‌به‌گام |
| `best_g` | `dict` | `cell -> cost` | کمترین هزینه انباشته شناخته‌شده تا هر خانه |
| `expanded` | `list` | لیست خانه‌ها | ترتیب گره‌های بسط‌یافته جهت سنجش پیچیدگی زمانی |
